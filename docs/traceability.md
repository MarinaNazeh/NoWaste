# Traceability

Each SRS requirement, the user story it traces to, the tests that check it, the test level and its status.
Level is Unit, Integration (server with the real test database), Component (app screens with React Native Testing
Library, API mocked) or Manual (on the phone). Test IDs are the start of the test names.

# C-09 Reservation Service

SDD 3.2.1 and 5.2. One bag per reservation; card and no-card reservations; hold and check-in; cancellation and refund decision; release of bags; no over-reservation.
Provides IReservation. Requires IPayment, IPickupCode, IWaitlist, INoShow, INotification.
SRS: FR-RES-02 to 09, FR-RES-12, E-RES-01 to 05, BR-02 to 06.
